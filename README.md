# ช่างคิดช่างทำ — เว็บไซต์สื่อการเรียนรู้งานช่าง ม.6

เว็บไซต์แบบ Static HTML/CSS/JavaScript ไม่มี PHP ไม่มีฐานข้อมูล และไม่ต้องติดตั้งเซิร์ฟเวอร์

## โครงสร้างไฟล์

- `index.html` หน้าเว็บไซต์หลัก
- `style.css` รูปแบบและการแสดงผล Responsive
- `script.js` เมนู บทเรียน แบบทดสอบ 10 ข้อ และตรวจคะแนน
- `assets/toolkit.svg` ภาพประกอบที่สร้างสำหรับเว็บไซต์

## เปิดทดสอบในเครื่อง

1. แตกไฟล์ ZIP ก่อน
2. เปิดโฟลเดอร์และดับเบิลคลิก `index.html` ด้วย Chrome, Edge, Firefox หรือ Safari
3. ลองเปิดแต่ละบทเรียน กดปุ่มถัดไป และทำแบบทดสอบ 10 ข้อ เพื่อดูคะแนนพร้อมเฉลย
4. กด F12 ในเบราว์เซอร์ เลือกโหมดอุปกรณ์ (Device Toolbar) เพื่อดูรูปแบบโทรศัพท์

หมายเหตุ: เว็บไซต์ทำงานได้โดยไม่ต่ออินเทอร์เน็ต ยกเว้นฟอนต์ Google Fonts ซึ่งจะใช้ฟอนต์สำรองของเครื่องแทน

## เผยแพร่ด้วย GitHub Pages

1. ลงชื่อเข้าใช้ GitHub และสร้าง Repository ใหม่ เช่น `workshop-classroom`
2. อัปโหลด **เนื้อหาภายในโฟลเดอร์** ทั้ง `index.html`, `style.css`, `script.js` และโฟลเดอร์ `assets` ไปยังระดับบนสุดของ Repository (อย่าอัปโหลดโฟลเดอร์ครอบเพียงโฟลเดอร์เดียว)
3. กด **Settings → Pages → Build and deployment**
4. ตั้ง Source เป็น **Deploy from a branch** เลือก Branch `main` และ Folder `/(root)` แล้วกด Save
5. รอระบบเผยแพร่ และเปิด URL รูปแบบ `https://USERNAME.github.io/workshop-classroom/` (แทน USERNAME และชื่อ Repository ตามจริง)

## การประเมิน

- แบบทดสอบ 10 ข้อ ข้อละ 1 คะแนน
- ต้องตอบทุกข้อก่อนส่งคำตอบ
- ระบบตรวจคำตอบในเบราว์เซอร์ แสดงคะแนน /10 และเฉลยพร้อมเหตุผล
- ไม่มีการเก็บชื่อหรือคะแนนบนเซิร์ฟเวอร์ เมื่อรีเฟรชจะเริ่มใหม่

## ขอบเขตความปลอดภัย
